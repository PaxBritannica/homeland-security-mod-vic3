# Historical Starting Technologies

Several countries begin the game with intelligence technologies already researched for historical authenticity.

## Location
These configurations are found in `common/history/countries/`

## Critical Compatibility Note
**PRG (Paraguay)** and **AUS (Austria)** MUST start with Era 2 technology `tech_secret_service` to prevent multiplayer crashes. Both countries spawn with the `law_secret_police` law, which now requires Secret Service to be researched first.

## Technology Assignments

### Era 2: Secret Service
The following great powers start with established intelligence services:
- Britain (GBR)
- France (FRA)
- Austria (AUS) - *required for stability*
- Russia (RUS)
- Prussia (PRU)
- Paraguay (PRG) - *required for stability*

### Era 3: Extended Network
**Belgium (BEL)** uniquely starts with advanced intelligence capabilities and National Guard so it can start building Secret Service HQs right away. This is done reflecting its historical position as:
- One of Europe's leading intelligence investors
- The speculated birthplace of the first formal intelligence bureau
- Option for those who want to try out a fast start

## Infrastructure
No countries begin with intelligence buildings pre-constructed. All nations must still intelligence buildings from the ground up.
